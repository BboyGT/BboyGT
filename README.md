# Hi, I'm BboyGT

I build practical software that turns messy real-world workflows into usable tools: AI assistants, realtime collaboration apps, audio utilities, productivity systems, mobile experiments, and polished web dashboards.

My projects usually sit at the edge where frontend craft meets automation: React and Next.js interfaces, Electron desktop apps, Android/Kotlin builds, WebRTC, local AI, speech tooling, OCR, analytics, and developer utilities.

## Current Focus

- AI agents and personal automation for everyday work
- Audio, transcription, translation, and system capture tools
- Realtime collaboration, remote assistance, and screen workflows
- Productivity apps that change behavior, not just track it
- Frontend tools for debugging layouts, motion, and user experience

## Direction

I like building products that feel useful quickly: tools with clear workflows, fast feedback loops, and enough polish that people can actually live inside them. The theme across the work is simple: make computers do more of the tedious parts while the human stays in control.
