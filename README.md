## Hey, I'm Godstime

I am a software engineer who enjoys building products from the interface down to the logic behind it. Frontend is where I move fastest, but I am not boxed into only screens. I like the full path: the idea, the UI, the data, the edge cases, the payment flow, the realtime behavior, the debugging, and the small polish that makes something feel real.

Right now I am building public projects around wellness apps, fitness products, browser debugging tools, CSS demos, accessibility, dashboards, and practical full-stack features. I am interested in work where I can build, learn quickly, contribute properly, and keep shipping.

```txt
My lane:
Software engineering -> products, systems, APIs, integrations, debugging
Frontend strength    -> React, Next.js, TypeScript, CSS, accessibility, animation
Product features     -> auth, payments, subscriptions, dashboards, realtime rooms
Backend tools        -> Node, Express, MongoDB, Prisma, Supabase, Socket.io
Public learning      -> clean demos, useful READMEs, bug explanations, open source
```
