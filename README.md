## Hi, I'm Godstime

I design and build web experiences that feel sharp, useful, and intentional. My work sits around frontend engineering, product UI, accessibility, technical writing, and full-stack app flows.

I like projects where the details matter: a dropdown that escapes a scroll container, a CSS grid bug explained clearly, a payment flow that cannot be spoofed from localStorage, or a wellness app that feels calm instead of noisy.

```txt
Current lane:
Frontend architecture -> React / Next.js / TypeScript
UI craft              -> responsive layouts, animation, accessibility, design systems
Browser deep-dives    -> CSS Grid, overflow, stacking context, Popover API, Gamepad API
Product systems       -> auth, payments, subscriptions, dashboards, real-time rooms
Writing style         -> practical demos that teach the bug and the fix
```
